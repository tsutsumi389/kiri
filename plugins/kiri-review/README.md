# kiri-review

kiri が書き出した画像を Claude Code のペインに出し、場所ごとに「ここを直して」とコメントして Claude に渡す mod（関数フック製のプラグイン）。

## 使い方

- `/kiri-review <画像のパス …>` か、Claude に「この画像をペインで見せて」と頼む（Claude は `mcp__kiri-review__open` を呼ぶ）。画像は何枚でも、ディレクトリを渡せばその中の画像を名前順に全部並べる（64 枚まで）。
- 複数のときは上にサムネイルの一覧（番号つき、表示中は青枠、コメント数は赤丸）が出る。「←」「→」か「画像」の選択で大きく出す画像を切り替える。「一覧から外す」で 1 枚外せる。
- 直したい場所を画像の上でドラッグして選び（青い枠）、「コメント」に書いて Enter で追加する。クリックだけならその点のまわりの小さな範囲、選ばずに追加すれば画像全体へのコメントになる。付けたコメントは赤い枠と番号で画像に重なる。
- コメントは画像ごとに付く。「Claude に送る」で、全部の画像の分が画像ごとにまとまり、画像のパスと寸法、各コメントの元画像の画素範囲（と縦横の割合）がプロンプトとして届く。
- 「画像をコピー」で表示中の画像そのもの（縮小前）をクリップボードに入れる。PNG は透過のまま、JPEG と PNG 以外は PNG に変えて入れる。
- 一度開いたあとは、Claude が kiri を実行するたびに、書き出した画像が一覧に入る（同じパスは差し替え、新しいものは末尾へ）。`--json` の結果があれば `outputs[].path` を全部拾うので、`--derive` / `--sizes` や `batch` の何枚もの出力も並ぶ。無ければ `-o` を拾う。

## 制約

- 画像を描くのは Claude Code Desktop のペインだけ（`Svg` 要素）。ターミナルではコメント欄のみで、コメントは画像全体へのものになる。
- ドラッグは、画像の上に重ねた透明な `Client`（`hooks/drag.tsx`）がポインタを受けて取る。`Client` の座標は文字のマス単位なので、範囲の細かさはペインの文字の大きさほど（端末が画素を返す面ではそれより細かい）。
- 縮小画像は macOS の `qlmanage` と `sips` で作る（HEIC の回転指定を反映するため Quick Look を使う）。macOS 専用。
- `Svg` の source は 131072 文字まで、`Select` の選択肢は 64 個まで。超えるとペインごと描かれない。一覧のサムネイルは上限に入る枚数だけ描き、残りは「画像」の選択から選ぶ。

## インストール

```
/plugin install kiri-review --marketplace tsutsumi389/kiri
```

## 開発

```
claude plugin validate plugins/kiri-review
claude plugin test plugins/kiri-review
```
