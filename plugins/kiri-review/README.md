# kiri-review

kiri が書き出した画像を Claude Code のペインに出し、場所ごとに「ここを直して」とコメントして Claude に渡す mod（関数フック製のプラグイン）。

## 使い方

- `/kiri-review <画像のパス …>` か、Claude に「この画像をペインで見せて」と頼む（Claude は `mcp__kiri-review__open` を呼ぶ）。画像は何枚でも、ディレクトリを渡せばその中の画像を名前順に全部並べる（64 枚まで）。
- 複数のときは上にサムネイルの一覧（番号つき、表示中は青枠、未解決のコメント数は赤丸）が横一列に出る。サムネイルをクリックすると、その画像を大きく出す。6 枚より多ければ、隠れている側の端に ‹ › が出て、押すと一覧が横に流れる（一覧の上の横ドラッグでも流せる）。一覧で全部を選べないときだけ「画像」の選択も出る。「一覧から外す」で 1 枚外せる（コメントのある画像は、もう一度押して確かめる）。
- 画像の上の一行が、いま次にすることを案内する。直したい場所を画像の上でドラッグして選び（青い枠）、「コメント」に書いて Enter で追加する。クリックだけならその点のまわりの小さな範囲、選ばずに追加すれば画像全体へのコメントになる。付けたコメントは赤い枠と番号で画像に重なり、下の一覧に同じ番号と本文が並ぶ（× で消す）。画素範囲は Claude に送る文にだけ入る。
- 「Claude に送る」は送るコメント（未送信と「まだ」）が 1 件でもあるときだけ出る。
- **拡大**: 範囲を選んで「拡大」を押すか、コメントの行の「拡大」を押すと、その範囲（周りに各辺 15% の余白、細長すぎれば短い辺を長い辺の半分まで広げる）を元画像から原寸で切り出し、長辺 640 px に引き伸ばしてペインに大きく出す。拡大の上でもドラッグして範囲を選んでコメントでき、その画素範囲は元画像の座標に戻して記録する。拡大中に選ばずに書けば、拡大している範囲へのコメントになる。「全体に戻る」で全体表示へ。
- **前後の比較**: 画像は読んだときに元画像を `.cache/versions/` へ写しておく（APFS なら `cp -c` の複製で場所を取らない）。同じパスの画像が kiri の再実行などで差し替わる（mtime か寸法が変わる）と版が進み（見出しに「第 N 版」）、一つ前の版の縮小と写しを残す。「前の版と比べる」／「今の版を見る」で切り替えて見比べられる。拡大中なら、前の版の写しから同じ範囲（寸法が変わっていれば同じ割合の位置）を切り出して比べる。拡大中に差し替わったら、同じ範囲で作り直す。前の版を出している間はコメントを付けない。残す前の版は一つだけで、それより古い写しは片付ける。
- **透過の下地**: 透過のある画像は、ペインの縮小も拡大も市松模様の上に重ねて出すので、切り抜きの縁に残った背景が見える（Claude に送る切り抜きは従来どおりマゼンタの上）。
- **指摘の追跡**: 送ったコメントは消さず「送信済み」として残る。その画像が差し替わると「確認待ち」になり（トーストにも件数が出る）、各行の「直った」「まだ」で確かめる。「まだ」を付けたものは次の「Claude に送る」に再指摘として入る（直ったを付けたものは入らない、付け直しもできる）。一覧の赤丸と「画像」の選択の件数は、直ったを付けていないコメントの数。枠と番号の色は、未送信と「まだ」が赤、送信済みが灰、確認待ちが橙、直ったが緑（点線）。未送信・「まだ」・確認待ちのコメントのある画像は、別の画像を開き直しても一覧に残る（送信済みのまま差し替わっていないものや、直ったものだけの画像は残さない）。直ったを付けていないコメントのある画像を外すときは確かめる。一覧が 64 枚を超えて画像を外したときは、黙って消さずにそのことを知らせる。差し替えで画像の寸法が変わったら、コメントの範囲を同じ割合の位置へ移す（画像全体へのコメントは全体のまま）。
- コメントは画像ごとに付く。「Claude に送る」で、全部の画像の分が画像ごとにまとまり、画像のパスと寸法、各コメントの元画像の画素範囲（と縦横の割合）がプロンプトとして届く。範囲を選んだコメントには、その範囲を切り抜いた PNG のパス（`.cache/crops/` の下）も添える。切り抜きは確認用で、範囲の周りに各辺 15% の余白を付け、長辺を 512–1568 px にそろえ、透過部分はマゼンタ（#ff00c8）の上に重ねて縁の残りが見えるようにしてある。Claude は Read で開いて見る。画像全体へのコメントは切り抜かない。切り抜けなかったコメントは座標だけで送る。
- **kiri の指摘**: kiri を `--json` で走らせると、結果の `warnings[]` のうち HALO_REMAINS / CONTOUR_ROUGH / RIM_CONTAMINATED の `data.regions`（入力画像の画素、両端を含む）を、`outputs[]` の `source_rect` / `content_rect` で出力画像の画素へ写し（source_rect の外は切り詰める）、橙の点線と K 番号で画像に重ねる。下の「kiri の指摘」の一覧に、コードと score が並ぶ。「拡大」で、その範囲を拡大する。「コメントにする」で、警告のコードを含む未送信のコメントになる。`source_rect` の無い出力（`--rotate`）は範囲を写せないので出さない。出し直して画像が差し替わると、新しい結果の指摘に入れ替わる（`--json` 無しで書き直されたら消える）。前の版には重ねない。
- **入力画像の範囲**: kiri の出力画像（`source_rect` / `content_rect` のあるもの）へのコメントは、送るときに入力画像のパスと、逆算した入力画像の画素範囲（両端を含む）、その四隅の多角形（画素と normalized）を添える。多角形は `--fg-polygon` / `--bg-polygon`（normalized は `--normalized` と併せて）にそのまま渡せる。余白（content_rect の外）だけのコメントと、画像全体へのコメントには添えない。
- **edge_repair**: 結果に `edge_repair`（`--edge-repair auto`）があれば、解き直した数と、縁残り・ギザギザ・縁の混色の前後を一行で出す。
- 「画像をコピー」で表示中の画像そのもの（縮小前）をクリップボードに入れる。PNG は透過のまま、JPEG と PNG 以外は PNG に変えて入れる。
- 一度開いたあとは、Claude が kiri を実行するたびに、書き出した画像が一覧に入る（同じパスは差し替え、新しいものは末尾へ）。`--json` の結果があれば `outputs[].path` を全部拾うので、`--derive` / `--sizes` や `batch` の何枚もの出力も並ぶ。無ければ `-o` を拾う。

## 制約

- 画像を描くのは Claude Code Desktop のペインだけ（`Svg` 要素）。ターミナルではコメント欄のみで、コメントは画像全体へのものになる。
- ドラッグは、画像の上に重ねた透明な `Client`（`hooks/drag.tsx`）がポインタを受けて取る。`Client` の座標は文字のマス単位なので、範囲の細かさはペインの文字の大きさほど（端末が画素を返す面ではそれより細かい）。
- 縮小画像は macOS の `qlmanage` と `sips` で作る（HEIC の回転指定を反映するため Quick Look を使う）。透過のある画像の縮小は、市松模様に重ねるため JXA（AppKit）で作る。拡大は切り抜きと同じ手順（下記）で切り出し、`sips` で JPEG にして、Svg の上限に収まるまで長辺と品質を下げる。切り抜きは、透過も回転指定も無い画像なら `sips -c --cropOffset`、それ以外（透過、EXIF の回転、HEIC）は `osascript -l JavaScript` の AppKit（`NSImage` は表示の向きで読む）で切り抜いて背景色に重ねる。sips の切り抜きは回転前の画素に効き、背景に重ねることもできないため。macOS 専用。
- 前の版は画像ごとに一つだけ。写しは、読み込みのたびと起動時に、どの画像も指していないものを片付ける。合計が 2 GB を超えたら、古く写したものから消す（消えた前の版は拡大して比べられない）。写したあとに元画像の mtime を読み直し、写している間に書き換わっていたら写し直す。
- `Svg` の source は 131072 文字まで、`Select` の選択肢は 64 個まで。超えるとペインごと描かれない。一覧のサムネイルは上限に入る枚数だけ描き、残りは「画像」の選択から選ぶ。

## インストール

```
/plugin install kiri-review --marketplace tsutsumi389/kiri
```

## 開発

```
claude plugin validate plugins/kiri-review
claude plugin test plugins/kiri-review
```
